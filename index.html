Up and running in minutes

  1. Fork the template

    Click "Use this template" on GitHub to create your own copy of the repository

  2. Configure your services

    Edit config.yml and add the endpoints you want to monitor

  3. Enable GitHub Pages

    Go to Settings → Pages and set the source to the main branch

  4. You're live

    Your status page is published at username.github.io/repo

language: en
