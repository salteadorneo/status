Ligero por diseño

Menos infraestructura. Lo esencial cubierto.

El resultado son páginas rápidas y datos que puedes servir, enlazar o reutilizar sin desplegar una aplicación de estado aparte.

01

Comprueba tus servicios

Configura endpoints HTTP/HTTPS, puertos TCP o resolución DNS. Los checks se ejecutan cada diez minutos.

02

Publica el estado

Se generan una página general, páginas por servicio, historial, badges SVG y endpoints JSON estáticos.

03

Recibe aviso en GitHub

Cuando un servicio cae, se abre una incidencia; al recuperarse, la incidencia se cierra automáticamente.

De cero a publicado

Una configuración y listo.

  1. Usa la plantilla en GitHub.
  2. Añade tus servicios en config.yml.
  3. Activa GitHub Pages en los ajustes del repositorio.
